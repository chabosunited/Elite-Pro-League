# EPL v23 – Desktop Header Spacing

## Änderung
Der Desktop-Header wurde in klar getrennte Bereiche aufgeteilt:

1. EPL-Logo
2. Hauptnavigation
3. VM-/Admin-Steuerung
4. Utility-Icons, Profil und Abmelden

Auf großen Desktop-Auflösungen nutzt der Header eine breitere eigene Innenfläche und größere Abstände zwischen diesen Gruppen. VM PANEL / ADMIN werden zusätzlich durch einen dezenten Trenner von Benachrichtigungen, Nachrichten, Profil und Abmelden getrennt.

Der Slider, Footer, Mobile-Header und der übrige v22-Stand bleiben unverändert.

## Deployment
Keine D1-Migration und kein Wrangler-Befehl nötig. Für das Update reichen `src/app.js`, `src/styles.css` und `package.json`.
